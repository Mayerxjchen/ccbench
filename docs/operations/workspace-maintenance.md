# Workspace maintenance

The main repository contains reusable infra, runtime recipes, configuration templates and generic tests. Paper cases, scientific references and completed scientific runs belong to their paper/operator storage.

The 2026-09-11 reduction was authorized to retire built-in scientific cases and platform-specific compatibility code. Their prior maintenance policy and append-only decision-ledger.json are preserved together with all old assets in the external pre-slim archive. Current modified files were captured before cleanup.

Protect `.env`, operator credentials, `runs/compshare-orphans.jsonl`, current runtime locks, and any evidence still required by an active external paper. Never publish credentials. Historical evidence bytes must be preserved with a tested recovery copy before removing their working copies.

Caches such as `__pycache__`, `*.pyc`, `.pytest_cache` and `*.egg-info` are regenerated by Python, pytest or package installation. They are ignored by Git and are not evidence of an incomplete source cleanup.

Use exact reviewed paths for removal. Preserve unrelated dirty changes. A linked worktree is managed using `git worktree remove`, not direct filesystem deletion. Local cleanup does not authorize remote HPC/cloud deletion.

The pre-slim recovery package is documented in [the acceptance plan](../architecture/slim-infra-plan.md). Extract archives into a fresh directory and compare relevant hashes before restoring; never overwrite a working repository blindly.
