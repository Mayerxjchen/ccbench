# Public CIPS inputs

`CuInP2S6.cif` is the recovered periodic CIPS structure. `teacher/` contains
the recovered published DeePMD graph and its element map. These are the only
scientific payloads supplied to a Candidate. The Candidate must derive all
student data, exploratory trajectories, labels, models, and metrics during its
own scheduler-backed run and record hashes/provenance in `final/manifest.json`.
