DeePMD-kit `input.json` requires a **`type_map`**: a JSON array of element symbols for all chemical species in the training data.

Read `/app/deepmd_notes.txt` for the ordering rule used in this benchmark.

Your training set contains **only hydrogen and carbon**. Write the **correct `type_map` JSON array** (compact form, no spaces after commas) to `/app/out.txt`.

Example format: `["H","C"]`
