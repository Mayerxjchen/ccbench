Create a methane (CH4) molecule using ASE and write its XYZ coordinates to `/app/CH4.xyz`.

Steps:
1. Activate the virtual environment at `/opt/chem-env`: `source /opt/chem-env/bin/activate`
2. Use ASE to create a methane molecule: `from ase.build import molecule`
3. Write the XYZ file to `/app/CH4.xyz`

The output file should be in standard XYZ format.
