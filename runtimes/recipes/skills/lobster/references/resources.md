# LOBSTER Resources

> Load this when: a LOBSTER question isn't covered locally — then consult the linked source.

- **LOBSTER program & manual** — http://www.cohp.de/ — official download, user manual, `lobsterin` keyword reference, and supported basis sets.
- **COHP/COOP methodology** — the LOBSTER papers (Dronskowski & Blöchl COHP; Deringer/Maintz/Dronskowski projected-COHP for plane waves) — cite the version-appropriate references; `lobsterout` prints the recommended citation.
- **Basis sets** — `pbeVaspFit2015` (and alternatives) are documented with the program; match the basis to the VASP PAW valence.
- LOBSTER launch path and thread policy belong in the submitted job descriptor, not here.
